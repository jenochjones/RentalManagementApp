# Rental Property Tracker
Run in Spyder by setting this folder as the working directory, installing `pip install -r requirements.txt`, and running `app.py`. Open `http://127.0.0.1:5000`.

The SQLite database is created automatically. The payoff-date and running total equals rental income minus recurring operating expenses, one-time costs, and mortgage interest paid. Principal is excluded because it builds equity. The home-page preview starts with the first scheduled payment in or after the current calendar month.
